# EvaluacionPOOHessemyOdalis
Prueba de POO

¿Por que ArrayList o LinkedList no son aceptables?
Porque son simplemente listas y en este caso necesitamos un HashMap, en el guardamos el identificador que es el username y los datos del usuario como lo son la contraseña, el correo y su nombre

¿Por que HashSet no resuelve el problema por sí solo?
Porque en HashSet no tienes un identificador unico, solo pide que el username sea valor unico y si utilizamos HashSet todos los valores ingresados desde la clase usuarios tendrian que ser unicos

¿Por que TreeMap no es la opción ideal?
Es una opción valida pero para la optimización de la app HashMap es mejor.
En el trabajo no nos pide ordenar por clave.

¿Cual es la unica estructura basa den hashing que resuelve todas las opreaciones en tiempo promedio constante?
HashMap
